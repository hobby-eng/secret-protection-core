# AUD-014 — Release audit of secret-protection-core

**Hold the unrestricted native release.** Five of the six Medium findings block release. They concern the lifetime of a permission guard, the Linux worker before and during admission, Unix shutdown, and effective authority on Windows. The default tests pass on four native runners. None of them exercised all five conditions. This decision applies to the Git source reviewed below.

### Findings and required verification

#### AUD-014-SEC001 — A live ClosedSecret callback can change protection on a foreign address after fork

**Medium · release blocker · open on the frozen commit.** The post-fork owner rule should cover cleanup on both normal return and unwinding. The temporary Open guard keeps only an address and length. Its destructor calls allow even in a different generation. The outer ClosedSecret destructor checks the generation.

If a supported continuing Unix child returns from a callback and the old range has been reused, it can remove access from unrelated pages. An unmapped range ordinarily makes the call fail. No secret read or collision observed.

Carry the generation to the permission guard and skip foreign-page changes. Explicitly document outstanding borrows. Cover a normal callback return in a continuing single-thread child and confirm no permission operation on any foreign range. Keep the ordinary-owner regressions.

Source on the reviewed commit: [src/protect/closed.rs:63,175](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/src/protect/closed.rs#L63); [src/os.rs:97,195](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/src/os.rs#L97); [src/os/unix.rs:123](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/src/os/unix.rs#L123).

#### AUD-014-SEC002 — The Linux worker cannot guarantee a clean descriptor table before library startup

**Medium · release blocker · open on the frozen commit.** For the advertised pre-main guarantee the child must drop every nonstandard inherited descriptor before library constructors. The Linux close list is taken from the parent in advance. Failed listing becomes empty and failed classification drops an entry. A later child scan can see only handles still present. Apple uses a different spawn facility.

Startup code can see a parent resource that the handshake cannot retrospectively account for. A descriptor that remains visible at serve still causes refusal. No first secret is sent before a valid handshake.

Use a child-side close-from or equivalent atomic close-on-exec policy after redirecting standard streams. Fail on uncertain enumeration if the platform must use a fallback. Describe any remaining guarantee narrowly. Test ordinary early library initialization, parent listing refusal, concurrent descriptor changes and the documented fallback, on Linux and macOS.

Source on the reviewed commit: [src/os/unix.rs:397,419,551,574,609](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/src/os/unix.rs#L397); [tests/worker.rs](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/tests/worker.rs); [README.md](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/README.md).

#### AUD-014-SEC003 — Forced Unix shutdown addresses a worker by a reusable process number

**Medium · release blocker · open on the frozen commit.** A termination request may affect only the worker created by this object. The last nonblocking wait and kill by numeric PID are distinct operations. When the system or another reaper collects the worker in that interval, its number is free.

A permitted unrelated process assigned that number could receive SIGKILL. Normal exclusive reaping pins an exited worker until it has been waited for. No wrong-process signal was sent in this audit.

Use a stable child identity acquired at spawn, or decline forced termination on a path where identity cannot be retained. Use a test double for identity retirement and verify cleanup under normal and automatic reaping without signaling unrelated processes.

Source on the reviewed commit: [src/os/unix.rs:296,329,341](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/src/os/unix.rs#L296); [tests/worker.rs](https://github.com/hobby-eng/secret-protection-core/blob/fb2a6d345caf8eb58097f013f12e43985402150f/tests/worker.rs).

#### AUD-014-SEC004 — Worker admission can accept thread-only isolation

**Medium · release blocker · open on the frozen commit.** The documented whole-process worker must establish that scope before accepting a secret. A Unix clean descriptor list need not imply a single thread. A linked library may have started a thread before main. The parent enforces only its caller-supplied list. A thread-scoped confirmation can therefore satisfy a requested individual protection.

A caller that omitted WholeProcess under the worker examples could admit a process with less isolation than expected. A caller requiring WholeProcess is refused when the condition is false.

Make the worker admission contract explicit. Enforce WholeProcess for a worker promising that scope or make selection of a weaker scope explicit. Exercise a benign startup with an extra thread and no extra file descriptors. Confirm refusal for strict admission and document any deliberately weaker mode.

#### AUD-014-FUN001 — A failed worker shutdown can leave a later exit unreaped
